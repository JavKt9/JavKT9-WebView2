01Bienvenida

Empezar en pocos minutos

JavKT9 organiza una colección local de películas. Esta guía explica cómo usar la compilación de prueba 0.8.1 RC2 de Windows sin poner en riesgo tu colección principal.

▤
01 / ARCHIVOS

Colección local

Los títulos y las fichas se guardan en archivos .gcs.

⌕
02 / INFORMACIÓN

Datos y portadas

Completá fichas manualmente o consultá información mediante JavLibrary/WebView2.

◇
03 / SEGURIDAD

Respaldos ZIP

Guardá copias con colección, portadas y favoritos personales disponibles.

Entorno RC2Esta guía corresponde a una compilación local de prueba. Esta edición RC2 es de prueba y no una versión pública definitiva. Usá una colección de prueba para ensayar restauraciones.

Inicio rápido

01

Abrí JavKT9

En el entorno local validado, usá JavKT9-RC2-Inicio.exe. No necesitás ejecutar PowerShell por separado.

02

Abrí o creá una colección

Entrá en File → Open para elegir un archivo .gcs, o usá File → New para crear uno.

03

Agregá y guardá

Usá Add Movie, completá la ficha y guardá con Save.

03Archivos .gcs

Crear, abrir y guardar

La colección es el archivo principal de trabajo. Guardarla es distinto de generar una copia de seguridad completa.

01

Nueva colección

Elegí File → New. Se iniciará una colección nueva en la que podrás añadir fichas.

02

Abrir una colección existente

Elegí File → Open, seleccioná tu archivo .gcs y esperá a que cargue el listado.

03

Guardar los cambios

Después de editar una ficha, hacé clic en Save o usá File → Save. Para cambiar de nombre o ubicación, utilizá Save As.

ARCHIVO DE COLECCIÓN

MiColeccion.gcs

Contiene las fichas y datos de la colección.

COPIA DE SEGURIDAD

GCJav_MiColeccion_...zip

Incluye la colección, sus portadas y, cuando existen, favoritos de actores/directores.

Consejo de seguridadConservá intacta la colección original durante las pruebas de RC2; trabajá sobre una copia y mantené un respaldo externo.
04Contenido de la colección

Fichas, búsquedas y metadatos

Cada elemento del listado representa una película. Podés editar la información disponible y utilizar las herramientas de búsqueda de la interfaz.

✎
EDICIÓN

Campos de la ficha

Incluye datos como código, títulos, fecha, director y otros campos visibles en General y Details.

★
ORGANIZACIÓN

Campos personales

Entre los campos previstos están Visto, Favorito, Puntuación, Etiquetas y Comentarios.

◎
INFORMACIÓN WEB

Consulta de datos

La obtención de metadatos y portadas se realiza con JavLibrary y el componente WebView2.

Flujo recomendado para una ficha

Añadir película›Verificar el código›Completar datos›Guardar
01

Agregar

Usá Add Movie y seleccioná la ficha en el panel izquierdo.

02

Revisar el resultado

Si la consulta externa trae datos, verificá que correspondan al código correcto antes de guardar.

03

Trabajar desde el listado

El clic derecho sobre una película muestra el menú contextual; esta función ya fue validada en RC2.

Consulta externaSi JavLibrary no devuelve información, puede deberse a una ficha inexistente, cambios del sitio o restricciones temporales. No se debe interpretar como pérdida de tu colección.
05Organización personal

Favoritos de películas y personas

JavKT9 distingue entre marcar una película como favorita y guardar favoritos personales de actores y directores.

EN LA FICHA

Favorito de película

Campo Favorito asociado a un título de la colección.

LISTA INDEPENDIENTE

Actores y directores

Lista personal separada del archivo .gcs.

01

Abrir favoritos de personas

Ingresá en Edit → Favoritos de actores y directores…, o utilizá el menú de clic derecho.

02

Gestionar la lista

Usá las opciones disponibles para incorporar o quitar nombres.

03

Proteger los datos

Los favoritos de personas se almacenan por separado; el backup ZIP de RC2 intenta incluirlos cuando el archivo está disponible.

Diferencia importanteExportar un listado en CSV o HTML no equivale a copiar toda la información personal ni las portadas. Para respaldar, usá la función específica de copia de seguridad.
06Protección de datos

Copias de seguridad y restauración

El respaldo ZIP es la herramienta recomendada para recuperar tu colección de prueba junto con sus imágenes y otros datos disponibles.

Crear un backup

01

Abrir una colección guardada

Primero asegurate de tener una colección .gcs abierta y guardada.

02

Crear copia

Entrá en File → Crear copia de seguridad. JavKT9 generará un ZIP y comprobará su contenido antes de informar éxito.

03

Localizar el archivo

Usá File → Abrir carpeta de backups o buscá en Documentos\JavKT9\Backups.

Restaurar un backup

01

Trabajar con la colección de prueba

Abrí la colección de destino que deseás restaurar.

02

Elegir el ZIP correcto

Entrá en File → Restaurar copia de seguridad y seleccioná una copia de seguridad válida.

03

Confirmar con cuidado

Leé la advertencia: la restauración reemplaza los datos de la colección abierta. RC2 crea antes una copia local de seguridad.

ZIPcolección + portadas
10copias recientes por colección
RC2verificación de ZIP
Antes de restaurarGuardá por separado una copia de la colección que querés conservar. La restauración es una operación de reemplazo, no una fusión automática.
07Otros formatos

Importar y exportar

Estas funciones sirven para intercambiar datos y listados. No sustituyen al respaldo ZIP de la colección completa.

↓
IMPORTAR

File → Import

Las opciones previstas en esta versión incluyen CSV y GCstar (.gcs). Revisá los campos de origen y destino.

↑
EXPORTAR

File → Export

Las opciones visibles incluyen CSV y HTML. Son útiles para compartir datos o consultar listados.

Cómo hacerlo de forma segura

01

Prepará una colección de prueba

Hacé una copia antes de importar un archivo desconocido.

02

Verificá la correspondencia

Al importar, revisá la asignación de campos y controlá que no se dupliquen títulos por error.

03

Guardá y verificá

Después de importar, revisá algunas fichas al azar, guardá y creá un respaldo nuevo.

ImportanteLos archivos CSV y HTML no garantizan incluir imágenes ni favoritos personales separados de la colección.
08Personalización

Elegí el tema de la lista y aplicalo.

03

El tema seleccionado se conserva al cerrar y volver a abrir JavKT9.
